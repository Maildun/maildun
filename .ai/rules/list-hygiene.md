# List Hygiene

## List hygiene uses a plain table
Keep the workspace List Hygiene table in the same cardless presentation as Audiences and Campaigns. The kind heading, description, filters, selection bar, table, and paginator remain in the normal page flow; do not wrap them in SettingsPanel or Card.

## Filter and search use shared alignment
Match Campaigns and Transactional: the List Hygiene FilterMenu sits on the left and ListSearch on the right at sm and above using sm:justify-between; keep the controls stacked on smaller screens.
