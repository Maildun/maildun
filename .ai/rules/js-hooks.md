# Js Hooks

## Media library is a multi-file dropzone
The media grid and empty state are a dropzone for owners/admins. The dashed overlay is drag-only — keep the library surface clean until a file is dragged over it. Dropping files or using Upload posts files[] immediately (multiple, max 20). Do not put uploads behind a confirm dialog.
